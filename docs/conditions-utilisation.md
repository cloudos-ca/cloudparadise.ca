## 4. Description du Service

Cloud Paradise est une plateforme infonuagique qui transforme une demande — formulée en langage naturel
ou au moyen d'un gabarit — en un traitement exécuté sur du matériel de calcul dédié (GPU, CPU à haute
capacité, mémoire vive massive). Le Service comprend notamment :

- le traitement de documents (conversion, OCR, traduction, classement, publipostage, archivage) ;
- le traitement et la génération d'images ;
- le traitement de données massives et l'interrogation de jeux de données ;
- l'encodage et la conversion de médias audio et vidéo, la transcription et le sous‑titrage ;
- le calcul GPU / CUDA et la simulation ;
- le rendu 3D ;
- l'extraction de données web guidée (« web scraping ») ;
- la planification et la récurrence de ces traitements.

Un agent d'orchestration fondé sur l'intelligence artificielle sert à **comprendre l'intention** d'une
demande et à sélectionner le moteur d'exécution approprié ; le calcul final est effectué par des
moteurs déterministes dédiés. Vous reconnaissez que le catalogue de fonctionnalités, les moteurs
disponibles et la capacité de calcul peuvent évoluer dans le temps.

**6.4 Débit des crédits.** Les crédits sont débités selon la capacité de calcul effectivement

interruption due à une défaillance de notre infrastructure n'entraîne aucun débit supplémentaire.

Un Traitement demeure facturable pour la capacité déjà consommée lorsqu'il échoue en raison d'un
Contenu utilisateur invalide, d'instructions erronées ou d'un résultat que vous jugez insatisfaisant,
ainsi que lorsque vous l'annulez volontairement en cours d'exécution.

**Défaillance de notre infrastructure.** Lorsqu'un Traitement échoue pour une cause qui nous est
imputable — nœud de calcul indisponible, agent d'exécution injoignable, dépassement du délai
d'exécution que nous imposons, ou incident interne — sans produire de résultat exploitable, les crédits
